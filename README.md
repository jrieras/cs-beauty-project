# BRAND NAME Personal Care Landing Page

A bilingual personal care brand concept built with Vite, React, and Tailwind CSS.

## Run Locally

From this folder:

```bash
npm install
npm run dev
```

Then open the local URL Vite shows in Terminal.

## Image Asset

The hero moodboard expects this file:

```text
public/images/brand-world-board.png
```

If that image is missing, the page shows a CSS fallback moodboard so the layout still works.

## Edit Content

Most English and Spanish content is in:

```text
src/data/siteContent.js
```

The page sections live in:

```text
src/components
```

## Build

```bash
npm run build
```

The final production files will be created in `dist`.
